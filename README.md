# Water Fields

An Openplanet plugin for creating and managing custom water fields in Trackmania maps. 

## Layout

Everyhting that will ship with the plugin lives in `src/`. Everything outside of this folder is ignored when building.

Water stays within the active map's X/Z borders by default, using its grid size at 32 metres per cell.

## Build

```powershell
python _build.py
```
